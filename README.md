# 주변개선

사진 한 장으로 우리 주변을 더 안전하고 편리하게 — Expo(React Native) 안드로이드 앱.

| 기능 | 내용 |
|---|---|
| 화재안전 지킴이 | 콘센트·멀티탭 사진으로 화재 위험 후보와 관리 방법 안내 |
| 책상정리 개선 | 책상 사진과 예산으로 정리용품 추천, 정리 후 모습 예시 |
| 맞춤 안경 추천 | 얼굴 사진으로 어울리는 안경 3가지 추천, 착용 모습 3종 비교 |

## 설치

[Releases](../../releases/latest)에서 `jubyeon.apk`를 받아 설치합니다.
바로 받기: https://github.com/beomgwani-cyber/jubyeon-app/releases/latest/download/jubyeon.apk

처음 실행하면 **설정**에서 본인의 OpenAI(ChatGPT) API 키를 입력해야 합니다. 키와 기록은 휴대폰 안에만 저장되고,
사진은 분석을 위해 OpenAI 서버로 전송됩니다.

## 안내

AI 보조 결과이며 전문가의 점검·진단을 대신하지 않습니다. 안경 착용 이미지는 AI 합성 예시이며
실제 안경테 치수·시력교정 효과를 보증하지 않습니다.
